用户要求：根据 `svgs/` 下 5 份**网页端**设计稿的样式，生成**移动端网页显示设计稿**。

**桌面稿概况**（先渲染成 PNG 逐张过目后再动手）：`svgs/{home,exam-list,exam-detail,practice,result}.svg`，
1440×960（result 1440×1016），纯矢量无位图。设计语言：
- 暖白底 `#FAF9F6`、白卡片 + `#EBE8E2` 描边、深墨绿主色 `#1F4A45`、
  状态徽章（灰 `#F0EEE9`/`#5B6663`、琥珀 `#FBF0D9`/`#9A6B12`、绿 `#E3F1EA`/`#2E7D5B`）、红 `#B04A3E`
- 衬线大标题（Georgia 系）+ 无衬线正文；顶部导航（logo+EXAM ARCHIVE 徽标+AL 头像）；表格 + 进度条 + 题号格子

**产出**（全部手写 SVG，`viewBox` 375 宽，文案与数据沿用桌面稿）：
- `svgs/mobile/home.svg`（375×1120）：导航收进底部标签栏（Home/Exams/Study/Settings，激活项顶部短横条），
  按钮全宽纵排（触达 44+），右栏「Your Performance」下移为整宽卡片
- `svgs/mobile/exam-list.svg`（375×1040）：表格 → 卡片列表（年份 + 徽章 + 进度条 + Open），
  搜索/年份筛选整宽化，尾注「Showing 6 of 17 papers」
- `svgs/mobile/exam-detail.svg`（375×1140）：Section 卡纵排（**序号圆徽即题组编号，标题去掉「Section N:」前缀**，
  否则与右侧状态徽章重叠），Instructions 右栏 → 整宽卡片，按钮纵排
- `svgs/mobile/practice.svg`（375×1800，**双画板**）：①主答题屏（右侧栏收起、题号/章节进度前移、

- `svgs/mobile/result.svg`（375×1120）：大分数移到眉标行右上避免与标题相撞；三统计卡一行三列；

- `svgs/mobile/index.html`：总览预览页（深底 + 手机壳框 + 每页重排要点注释）

**自检方法**：Playwright 把每份 SVG 截图后逐张肉眼检查，共抓出并修复 4 类问题：
1. **CSS 覆盖 fill 属性**：`text { fill: #1A2626 }` 会压过 `fill="#FFFFFF"`（表现属性优先级最低），
   所有白字/彩字被渲染成深色 → 改 `text:not([fill]) { fill: #1A2626 }`，一处修改全局生效
2. 详情页 Section 标题与右侧徽章重叠 → 标题去掉「Section N: 」前缀（序号已在圆徽里）
3. 结果页大分数与标题相撞 → 分数移至眉标行右上；Breakdown 行标签同样去前缀
4. 练习页头部标题被计时器裁切 → 标题下移到第二行，章节名并入进度条标签

## Design Direction + Design System 草案（docs-next/，**纯分析，未改代码**）

用户要求：分析 PC + Mobile 两套 SVG 设计稿，提取视觉语言/布局/Typography/颜色/Spacing/组件/响应式规则，
并与现有项目结构建立映射，输出到 `docs-next/`。产出 3 个文件：

- `docs-next/README.md`（索引 + 三句话总结 + 6 个待决策项）
- `docs-next/design-direction.md`（方向、5 条原则、视觉语言、版式哲学、字体/色彩方向、动效、a11y、现状 Gap、S1-S3 落地路径、开放问题）
- `docs-next/design-system.md`（Token 表 + 16 个组件规格 + 18 条响应式规则 + 代码映射表 + 迁移顺序）

**核心结论（后续做 UI 时直接可用）：**

- **方向**：English2 应从"默认组件搭出来的可用界面"变成"安静的真题档案馆" —— 衬线标题 + 暖白纸感 + 深墨绿单一强调色。
- **差距约 60% 是 Token 层替换**（主色 indigo→`#1F4A45`、底色纯白→`#FAF9F6`、
  `--font-heading` 从 `var(--font-sans)` 改衬线栈、描边 `ring-foreground/10`→`#EBE8E2`），
  **40% 是结构性**：缺 App Shell（顶栏/底部标签栏）、缺 Badge/Progress/Table/Sheet 组件、检索页 768 单栏→1280 + 2:1 分栏。
- **阅读区例外（重要）**：只加宽检索型页面（列表/详情/结果）；**题干/篇章/解析保持 720–768px**，
  现有 `max-w-3xl` 恰好等于该宽度，不必动。
- **中英混排**：标题走「拉丁衬线 + 中文黑体」—— CJK 回退**不要**进 serif，否则 Windows 落到宋体很难看。
- **实测发现 3 处配色不达 WCAG AA**（脚本算的，非估算）：
  `muted #6F7B77` on 暖白 = 4.18 → 改 `#6A7571`(4.54)；success on soft = 4.29 → `#2C7958`(4.53)；
  warning on soft = 4.14 → `#926511`(4.54)。`subtle #8A948F` 仅 2.97 → 限定装饰用途。
  描边对比度 1.16/1.48 < 3 ⇒ **状态必须有文字/图标冗余**。
- **移动端重排规则**：表格→卡片列表、右侧栏→下移整宽卡片或底部抽屉、顶部导航→底部标签栏、
  按钮并排→全宽纵排(44)、练习页高频操作→sticky 底部操作条。
- **设计稿领先实现的功能**（有稿无代码，别为对齐稿子临时造功能）：计时器、题号地图、Submit Examination。

**踩到的坑（写文档时）**：控制台直接输出中文会乱码（PowerShell 管道编码），
需要脚本结果落盘后再 Read，或让脚本只输出 ASCII 数字。

**边界**：本轮**只新增** `docs-next/`（3 个文件），未改 `src/`、`docs/`、线上库；
Phase 7 未提交改动与 `svgs/` 均保持原样。

## 现状代码审查（docs-next/refactor-audit.md，**纯审查，未改代码**）

用户要求：基于设计分析审查现有实现，区分「必须重构 / 建议重构 / 无需修改」，并确认应保留的业务逻辑与组件。
产出 `docs-next/refactor-audit.md`（第 4 个文件），结论：**6 必须 / 11 建议 / 14 保留 + 逐文件判定表**。

**🔴 必须重构（6）**
1. **主题 Token 重置** —— `:root` 是 shadcn 默认 indigo + 冷灰；`@theme inline` 已把 `--color-*` 指向 `:root`，
   ⇒ **只改 `:root` 值即可，不动任何组件**（成本极低）
2. **`--font-heading` 切衬线** —— 现在 `= var(--font-sans)`；接入点已有 6 处（各页 h1/年份/Card 标题），只差字族
3. **抽 `Badge`** —— 现有只有 `MistakeCard` 一处内联（`bg-destructive/10` 透明度叠色）；
   设计稿里徽章出现 4 类 6+ 处，且"透明度叠色"换主色后全要重调
4. **触控 44** —— Button 最大 `h-9`(36)；练习页上下题、错题页按钮与分类 tab（≈30）全部不达标
5. **对比度 + 状态冗余** —— 换色时必须一并修，否则把不达标色固化进 Token
6. **App Shell** —— 路由直接铺页面，每页各自「← 返回首页」；设计稿 5 页全带顶栏

**🟡 建议（11）**：Card 规格（16→12、ring→border）、容器宽度与分栏、列表表格化、详情信息结构、
练习页 sticky 操作条、结果页重排、Progress 组件、Input/Select、骨架屏去 `animate-pulse`、
图标统一 lucide（已在依赖里）、深色模式处置。

**🟢 明确保留（14，最重要的一节 —— 视觉重设计最易误伤）**
- 架构/数据层：分层链路、列白名单、**答案边界**、判分唯一出口 RPC + PracticeResult 唯一渲染处、
  排序契约、查询键、错误归一化、路由懒加载 + `:paperId` + UUID 预校验
- 业务逻辑（都踩过坑，禁止"简化"）：`canSubmit = hasChoiceItems || canRevealReference`、
  `answeredCount` 逐题判定、翻译题「离线作答+在线标记」且撤销=真删行、`onToggleTextAnswer` 未传不渲染、
  正确率按已判分客观题为分母、RPC 内错题收录
- 题库容错：json-utils 运行时窄化（不用断言）、chart 三态 + chart_url、passage/prompt 去重、
  titles 池 + letterOnly、`source_id.endsWith('-trans')` 判翻译
- 错题本域：两步查询 + 上次选择回查、**不写 updated_at**（有触发器）、不展示答案、**不做乐观更新**
- 已符合设计的实践：StateCard/FullScreen/CenteredState 文案风格、role=alert、fieldset/legend、
  reduced-motion 全局兜底、focus-visible ring
