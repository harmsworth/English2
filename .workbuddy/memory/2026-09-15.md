## English2 考研英语二真题学习系统 — Phase 1 项目初始化

- 技术栈落地版本：Vite 8.3.0 / React 19.3 / TypeScript 6.0.3 / Tailwind CSS 4.3.3 / shadcn CLI 4.21（preset `nova`）/ Base UI 1.8 / oxlint（模板已弃用 ESLint）。
- 关键坑位（务必记住）：
  1. shadcn init 报 `Could not load the workspace config` → 根因是 Vite 模板的 `tsconfig.json` 是 solution style（`files: []` + references），必须在**根 tsconfig.json** 里也补上 `baseUrl` + `paths`，否则 shadcn CLI 解析不到别名。
  2. TypeScript 6 已废弃 `baseUrl`，`tsconfig.app.json` 里不能写 `baseUrl`（报 TS5101），只写 `paths` 即可（TS 4.4+ 支持无 baseUrl 的 paths）。
  3. 新版 shadcn 生成的组件默认 `import { cn } from "cn"`，本项目规范改用 `@/lib/utils`（clsx + tailwind-merge），每次 `shadcn add` 后需改这一行。
- 项目约定：`data/exams/` 是 GitHub 源题库（Source of Truth），不可移动/重命名；`EXAM_FILES` 与 `GITHUB_RAW_BASE` 集中在 `src/lib/constants.ts`。
- 主题：白底深字 + 淡灰边框 + 克制的 indigo 主色（oklch 265 色相），字体 Geist Variable + 中文系统字体兜底，已加 `prefers-reduced-motion` 处理。
- 验证结果：`pnpm build` exit 0；`pnpm lint` 0 error / 1 warning（shadcn 自带 button.tsx 的 fast-refresh warning，可接受）；`pnpm dev` 返回 200。
