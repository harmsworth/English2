## 三句话总结

1. **换皮即见效**：主色 indigo → 深墨绿 `#1F4A45`、底色纯白 → 暖白 `#FAF9F6`、
   `--font-heading` 无衬线 → 衬线 —— 只改 `src/index.css` 就能拿到设计稿 80% 的气质。
2. **结构性差距有 3 处**：缺 App Shell（顶栏 / 底部标签栏）、缺 Badge / Progress 等基础组件、
   检索引擎页面宽度与分栏（设计稿 1280 + 2:1，现状 768 单栏）。
3. **有 3 项配色不达 WCAG AA**，已给出实测修正值；另有 6 个开放问题需先决策（见 direction §13）。
4. **代码审查结论（[`refactor-audit.md`](./refactor-audit.md)）**：架构与业务逻辑健康、全部保留；
   要动的是"皮"和"信息结构" —— 6 项必须重构（Token / 标题衬线 / Badge / 触控 44 / 对比度 / App Shell）、
   11 项建议、**14 项明确保留**（答案边界、判分逻辑、题库容错等，这些最容易被视觉重设计误伤）。
